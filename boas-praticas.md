# Boas Práticas de Git e GitHub

## 1. Criar commits descritivos
Utilizar mensagens claras nos commits para facilitar a identificação das alterações realizadas no projeto.

## 2. Trabalhar com branches
Criar branches separadas para desenvolver novas funcionalidades sem comprometer a versão principal do projeto.

## 3. Utilizar Pull Requests
Abrir Pull Requests para revisar as alterações antes de integrá-las à branch principal.

## 4. Manter o repositório atualizado
Utilizar o comando git pull para sincronizar o repositório local com as alterações disponíveis no GitHub.

## 5. Documentar os projetos
Manter um README.md atualizado com informações sobre o objetivo e a utilização do projeto.
